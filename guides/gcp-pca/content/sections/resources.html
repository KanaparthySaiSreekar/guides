Community sources reviewed for this guide

sanda82/gcp-pca ↗

A 2026 repo with over 300 original practice questions across all four current case studies, plus a study site. Its question banks are useful extra practice. Its short-notes case-study section still describes the retired HRL, TerramEarth and Mountkirk cases, and some limits there are out of date.

awesome-gcp-certifications: PCA ↗

A long index of courses, books, videos and exam-experience posts, from 2019 to 2026. Prefer entries dated after October 2025.

in28minutes Cloud Developer deck ↗

Built for the Professional Cloud Developer exam, but its scenario-to-solution tables on GKE, Cloud Run, IAM, Cloud Build and databases carry over well. It uses pre-2024 names.

r/googlecloud: PCA preparations 2026 ↗

Reddit blocks automated reading, so this thread wasn’t reviewed for this guide. Read it yourself for recent candidates’ experiences.

About “real exam question” sites. Sites selling “actual” PCA questions are brain dumps. Using them breaks the Google Cloud certification agreement and can get a certification revoked. Their answers are often wrong, and many still use retired case studies. This guide does not include or reproduce any real exam content.
